
# COVID-19 Global Impact Dashboard

## Project Overview

The COVID-19 Global Impact Dashboard is a data analytics project developed as part of the Veda Technology Data Analytics Internship – Day 38.

The project analyzes publicly available COVID-19 data to understand trends in reported cases, deaths, and vaccination progress across different countries and time periods.

## Objectives

- Clean and prepare COVID-19 data.
- Analyze daily cases and deaths.
- Calculate 7-day rolling averages.
- Compare country-level COVID-19 statistics.
- Explore vaccination coverage.
- Create interactive charts and a dashboard.
- Generate downloadable analysis files and an executive summary report.

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Plotly
- OpenPyXL
- ReportLab

## Key Features

- COVID-19 dataset cleaning and preprocessing
- Missing-value and duplicate handling
- Daily case trend visualization
- 7-day moving average analysis
- Top 10 countries by recorded cases
- Top 10 countries by recorded deaths
- Vaccination coverage comparison
- Interactive HTML dashboard
- Excel analysis workbook
- PDF executive summary
- Automatic ZIP file generation

## Visualizations

The project includes the following charts:

1. Daily New COVID-19 Cases
2. Seven-Day Average of New Cases
3. Top 10 Countries by Recorded Cases
4. Top 10 Countries by Recorded Deaths
5. Vaccination Coverage

## Dataset

**Source:** Our World in Data

Dataset:
https://covid.ourworldindata.org/data/owid-covid-data.csv

The dataset contains reported COVID-19 statistics, including cases, deaths, and vaccination indicators.

## Project Files

- `covid19_cleaned.csv` – Cleaned COVID-19 dataset
- `cleaning_log.csv` – Data cleaning details
- `global_summary.csv` – Summary statistics
- `covid19_analysis.xlsx` – Excel workbook with analysis sheets
- `covid19_interactive_dashboard.html` – Interactive dashboard
- `covid19_executive_summary.pdf` – Executive summary report
- `graph_1.html` to `graph_5.html` – Individual interactive charts

## How to Run the Project

1. Open Google Colab:
   https://colab.research.google.com/
2. Create a new notebook.
3. Copy the Python project code into a cell.
4. Run the cell with an internet connection.
5. Wait for the dataset download and analysis to finish.
6. Download the generated ZIP file.
7. Extract the ZIP file to access the project outputs.
8. Open the HTML dashboard in a web browser.

## Expected Outcomes

- Better understanding of COVID-19 trends.
- Comparison of reported statistics across countries.
- Identification of changes in daily case trends.
- Visualization of available vaccination data.
- Practice in data cleaning, analysis, and visualization.

## Limitations

Reported COVID-19 statistics may vary because of differences in testing, reporting methods, and data availability. The analysis describes recorded data and does not establish causation.
